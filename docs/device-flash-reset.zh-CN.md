# 设备 Flash 重置

nb1 v0.1.4 可为受支持的 blink(1) MK2 替换已保存的上电图案。它操作持久 Flash；普通 Off Action 只影响当前播放。这里的“重置”是写入 nb1 自带图案，默认 `off`，不是恢复设备的全部出厂设置。

## 预设

| 预设 | 保存的上电效果 |
| --- | --- |
| `off`（默认） | 每个存储行都是黑色并带正时长。 |
| `rainbow` | 沿色轮从红到洋红的八个步骤。 |
| `starlight` | 深蓝背景上的蓝白、紫色和暖色微光。 |
| `fireflies` | 黄绿与琥珀色光点，中间穿插暗段。 |

该操作不修改电脑上的 Pattern 库。若要立即熄灯，请使用普通 Off Action。

## 执行重置

必须明确选择目标设备。省略预设时使用默认图案：

```sh
nb1 device reset 20000001
nb1 device reset 20000001 rainbow
nb1 device reset 20000001 fireflies --json
```

设备必须空闲且可由 daemon 控制。nb1 会逐行校验持久行，在 RAM 中写入并读回，再只提交一次 Flash 保存请求。Flash 保存结果不确定时不会自动重试。电脑上的 Pattern 与设备上电状态彼此独立。

## 检查持久化

收到保存确认后，请断电再上电，确认灯启动时播放所选图案。在 macOS 上，即便设备已保存，USB 也可能未确认 Flash 保存。这时 nb1 会报告 `unconfirmed`；先检查设备并在冷启动后读回，再决定是否重置。重置 API 使用短时、一次性票据，避免响应丢失后重复保存。

## 支持的硬件

该预设操作适用于支持已审核 Flash 布局的匹配 MK2 固件（FW204、FW205）。MK3 的上电配置还会保存其他设置，因此不开放这种仅改图案的重置。通用设备端 Sequence 上传／播放和设备内存编辑属于另一项工作。本次记录的实物验收覆盖两只 MK2／FW204；不代表 MK3、所有平台的 USB 确认行为或光学校准均已验证。
